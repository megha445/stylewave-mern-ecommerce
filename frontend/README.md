# Customer Frontend

React storefront for customers.

## Main Responsibilities

- Browse products
- Search and filter catalog
- Manage cart
- Place COD or Razorpay orders
- View orders and submit reviews

## Run Locally

```bash
npm install
npm run dev
```

Default local URL: `http://localhost:5173`

## Environment

Copy `.env.example` to `.env` and update values when needed.
