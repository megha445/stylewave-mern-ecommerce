# Admin Dashboard

React dashboard for platform administrators.

## Main Responsibilities

- Approve or reject seller products
- Manage sellers
- Manage platform orders
- Review analytics and product reviews
- Use the admin AI operations assistant

## Run Locally

```bash
npm install
npm run dev
```

Default local URL: `http://localhost:5174`

## Environment

Copy `.env.example` to `.env` and update values when needed.
